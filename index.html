数回 · 怎么玩

SLITHERLINK — Nikoli 1989

沿点阵的格线连出一条单一闭合回路：不分叉、不交叉、不断头。

格子里若写着数字，表示这个格子的四条边中，恰好有几条属于回路。

操作

  • 画线：点击一条边，或按住拖动连续画
  • 排除：右键点击（触屏用「标记模式」），标出确定不在回路上的边
  • 擦除：在已画的边上再点一次
  • 快捷键 N 新题 · H 提示 · D 演示 · C 检查 · R 重来

三条能立刻上手的推理

  • 0 和 4：0 表示四条边都不在回路上，4 表示四条边全在——先圈出这些格子。
  • 3 挨着 0：3 的格子有四条边，被 0 挡掉共享的那条后，剩下三条必须全画。
  • 拐角不落单：每个点要么没有线，要么恰好两条线。某个点已经连了两条，其余方向立刻排除；只剩一条出路时，那条必须画。

关于本题库

每道题都由程序从一个随机的单一回路反向挖掘线索生成，并用回溯求解器反复验证解唯一——不会出现「另一个也说得通」的尴尬。
